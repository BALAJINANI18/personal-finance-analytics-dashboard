# 💰 Personal Finance Analytics Dashboard

A fintech-style analytics dashboard that analyzes personal expense data and presents insights through interactive visualizations and machine learning.

---

## 🚀 Features
- KPI cards (Total Expense, Average Expense, Top Category)
- Category-wise expense analysis (Bar Chart)
- Expense distribution (Pie Chart)
- Daily expense trend (Line Chart)
- Machine Learning–based expense prediction
- Clean, professional dashboard layout

---

## 🛠 Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
